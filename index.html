ข้อมูลชุมชน: วิกิชุมชน — บ้านต้นผึ้ง (ศูนย์มานุษยวิทยาสิรินธร) และเอกสารสรุปพื้นที่โจทย์ ภาคเหนือ จากการลงพื้นที่ 14–15 กรกฎาคม 2569

ภาพป่าทางเข้า สมาชิกชุมชนอธิบายการดูแลป่าและน้ำ ใบไม้ เครื่องอัด ภาชนะ และผ้า Eco-print มาจากเอกสารสรุปพื้นที่โจทย์ ภาคเหนือ · ลงพื้นที่ 14–15 กรกฎาคม 2569

แผนที่แสดงภูมิประเทศจากข้อมูลความสูงและพิกัดชุมชนที่เผยแพร่ไว้ ไม่แสดงแนวเขตป่าชุมชน ใช้ข้อมูลจาก OpenFreeMap, © OpenMapTiles, © OpenStreetMap contributors และ AWS Terrain Tiles / Tilezen

รอยอาคารโดยประมาณสกัดจาก Microsoft Global ML Building Footprints (manifest 13 สิงหาคม 2569) เป็นข้อมูลจากภาพถ่ายดาวเทียมและอาจคลาดเคลื่อน ไม่ใช่ขอบเขตหรือจำนวนบ้านที่ยืนยันภาคสนาม เลือกรอยอาคารจากระยะราว 1.2 กม. จากพิกัดที่เผยแพร่ รายละเอียดชุดข้อมูลอยู่ใน บันทึกที่มา; เผยแพร่ภายใต้ CDLA Permissive 2.0 (อ่านข้อความใบอนุญาต)
